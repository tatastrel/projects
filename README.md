## Артефакты системного анализа

В проектах я использую разные нотации под задачу: DFD для потоков данных, ER для БД, Use Case для требований, BPMN для процессов.

- **DFD (Data Flow Diagram)** — потоки данных между внешними сущностями и системой.  
  🗺️ [Исходник](projects/DFD.drawio)

- **ER‑модель (Entity Relationship)** — проектирование реляционной структуры и нормализация.  
  🗺️ [Исходник](projects/ERmodel.drawio)

- **Use Case** — сценарии взаимодействия пользователей с системой и обработка исключений.  
  🗺️ [Исходник](projects/USECASE.drawio)

- **BPMN** — моделирование бизнес‑процесса с ролями, сроками и условиями.  
  🗺️ [Исходник](projects/bpmn.drawio)
